# Política de Segurança - Doca Frontend

Privacidade e segurança de dados são as maiores prioridades do projeto **Doca**. Este documento descreve as versões suportadas e como relatar vulnerabilidades de segurança encontradas no frontend da aplicação.

---

## Versões Suportadas

O suporte de segurança é fornecido ativamente para as seguintes versões:

| Versão | Suportado |
| :--- | :--- |
| >= 1.0.0 | ✅ Sim |
| < 1.0.0 | ❌ Não |

---

## Como Relatar uma Vulnerabilidade

Por favor, **não abra uma issue pública** no GitHub para relatar problemas de segurança. Em vez disso, relate vulnerabilidades de forma responsável enviando uma mensagem privada ou e-mail para o mantenedor principal do projeto.

Ao enviar o seu relatório, inclua:
1. Uma descrição detalhada do problema de segurança.
2. Passos claros ou um script de prova de conceito (PoC) para reproduzir a vulnerabilidade.
3. Possíveis impactos na privacidade do usuário.

Agradecemos suas contribuições para manter o Doca seguro para todos!
